# Release notes

## 1.0.0 — 2026-11-22

First release. What is in it:

* Whitespace and comment removal, emoji and embed cleanup
* Anonymous request cache with publish/comment invalidation
* WP-CLI commands for purge, cleanup and conversion
* Redirect table with cache purge on change
* Site health tests for cache, encoders, cron and database
* WebP and AVIF copies generated on upload
* Sitemap index with XSL view and robots.txt line
* Consent-gated benchmark with downloadable request snapshot

Nothing was removed or deprecated, because nothing existed before this tag.
